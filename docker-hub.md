# OpenWebRX+ Docker images

OpenWebRX+ with SDR receivers and demodulators, built from Marat's Debian packages.

Install and manage these images with Docker Compose.

**The primary documentation is now maintained on GitHub:**

- [Installation, Docker Compose, configuration and troubleshooting](https://github.com/0xAF/openwebrxplus-docker-builder/blob/main/docker.md)
- [Image builder and native packages](https://github.com/0xAF/openwebrxplus-docker-builder)
- [Report an image issue](https://github.com/0xAF/openwebrxplus-docker-builder/issues)

Available images:

- [`slechev/openwebrxplus`](https://hub.docker.com/r/slechev/openwebrxplus): standard image.
- [`slechev/openwebrxplus-softmbe`](https://hub.docker.com/r/slechev/openwebrxplus-softmbe): image with the SoftMBE decoder.

For OpenWebRX+ features and general receiver setup, see the
[OpenWebRX+ Info Page](https://fms.komkon.org/OWRX/).
